# 🚀 Project Sprint — Student Project Management UI/UX

**Project Sprint** is a student-focused project management UI/UX design concept created to help college students organize academic projects, manage tasks, keep track of deadlines, and monitor project progress.

The project includes mobile and web interface designs created in Figma, focusing on usability, clear navigation, and a consistent visual experience.

## Project Overview

College students often need to manage multiple assignments, deadlines, and academic projects simultaneously. Project Sprint aims to provide a clear and organized interface that helps students plan their work and stay on track.

### Design Goals

- Simplify academic project organization.
- Make tasks and deadlines easier to track.
- Present project information in a clear, structured layout.
- Provide a consistent experience across mobile and web interfaces.
- Create an intuitive and user-friendly interface for students.

## Key Design Decisions

- **Information Hierarchy:** Organizes project details, tasks, and deadlines for quick access.
- **Navigation:** Keeps navigation simple and intuitive across mobile and web interfaces.
- **Layout and Spacing:** Uses consistent spacing and grouping to improve readability.
- **Typography:** Establishes a clear text hierarchy for better readability.
- **Color and Consistency:** Maintains a cohesive visual style across screens.
- **Mobile and Web Adaptation:** Adapts layouts to different screen sizes while preserving design consistency.
